# Лабораторная работа 1

## Задание

Создать веб-страницу с тремя колонками, которые адаптируются к разным размерам
экрана:

- на больших экранах (ширина больше 960px) колонки располагаются рядом друг с
  другом в один ряд (3 колонки в ряд);
- на средних экранах (от 601px до 960px) колонки перестраиваются в два столбца;
- на маленьких экранах (до 600px включительно) колонки располагаются одна под
  другой в один столбец.

## Реализация

Страница состоит из заголовка (`header`), основного блока с тремя колонками
(`main.columns`) и подвала (`footer`).

Каждая колонка — это отдельный `section` с классом `column`, содержащий
заголовок, текст и ссылку. Колонки объединены в общий контейнер `.columns`,
который использует CSS Grid (`display: grid`) с тремя равными по ширине
колонками (`grid-template-columns: repeat(3, 1fr)`).

Адаптивность реализована через два media-запроса:

- `@media (max-width: 960px)` — количество колонок в сетке меняется на
  `repeat(2, 1fr)` (два столбца);
- `@media (max-width: 600px)` — количество колонок меняется на `1fr` (один
  столбец, карточки идут одна под другой).

Дополнительно добавлены состояния `:hover` и `:focus-visible` для карточек
колонок и ссылок внутри них: при наведении/фокусе карточка слегка приподнимается
и получает тень, а ссылка меняет цвет и подчёркивается. Все стили вынесены в
отдельный файл `styles.css`, inline-стили не используются. Используются CSS
custom properties (`:root`) для цветов, отступов и радиуса скругления.

## Запуск

Открыть файл `index.html` в любом современном браузере (двойным кликом или через
"Открыть файл" в браузере). Внешние зависимости не требуются. Для проверки
адаптивности можно изменить размер окна браузера или открыть инструменты
разработчика (DevTools) и переключиться в режим эмуляции мобильных устройств.
