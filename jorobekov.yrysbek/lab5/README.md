# Лабораторная работа 5

## Задание

Вариант 17 Создать веб-приложение для заметок — органайзер с возможностью группировки и поиска информации.

Требования:
- создание, редактирование и удаление заметок;
- организация заметок по тегам;
- поиск по содержимому заметок;
- фильтрация по тегам и дате создания.

## Реализация

Приложение реализовано с использованием HTML, CSS и JavaScript.

Основные части приложения:
- `index.html` — структура страницы и формы для работы с заметками;
- `styles.css` — оформление и адаптивный интерфейс;
- `main.js` — логика создания, редактирования, удаления, поиска и фильтрации заметок.

Заметки хранятся в `localStorage`, поэтому сохраняются после перезагрузки страницы в том же браузере.

## Запуск

Откройте файл `index.html` в браузере.

Для работы приложения установка дополнительных зависимостей не требуется.
