# Лабораторная работа 5

## Задание

**Вариант 5 — канбан-доска (Trello-like).**

Разработать веб-приложение для управления задачами на React. Доска содержит
колонки «Сделать», «В процессе» и «Готово».

Требования:

- создание, редактирование и удаление карточек;
- организация карточек по колонкам;
- перетаскивание карточек между колонками (drag-and-drop);
- сохранение состояния доски в `localStorage`.

## Реализация

Приложение реализовано на React с использованием Vite.

- **`App`** — основной компонент, отображающий доску, колонки, поиск и
  статистику.
- **`TaskCard`** — карточка задачи с описанием, приоритетом и сроком выполнения;
  поддерживает редактирование, удаление и перетаскивание.
- **`TaskModal`** — форма создания и редактирования задачи.
- **`useState`** — хранит задачи, данные формы, поисковый запрос и состояние
  перетаскивания.
- **`useEffect`** — автоматически сохраняет задачи в `localStorage`.
- **`useMemo`** — фильтрует задачи по поисковому запросу.
- **`styles.css`** — стили доски, карточек, формы и адаптивного интерфейса.

Основные пользовательские сценарии:

1. Пользователь создаёт задачу и задаёт название, описание, приоритет и срок.
2. Пользователь редактирует или удаляет карточку.
3. Пользователь перетаскивает карточку в другую колонку, меняя статус.
4. Пользователь ищет задачи по названию, описанию или приоритету.
5. После перезагрузки страницы задачи восстанавливаются из `localStorage`.
