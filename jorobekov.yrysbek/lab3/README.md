# Лабораторная работа 3

## Задание

Вариант 17. Задача 3.

Необходимо реализовать функцию `maxSlidingWindow(arr, k)`, которая находит максимальные элементы во всех последовательных подмассивах (окнах) заданной длины `k`.

Функция получает два параметра:

- `arr` — исходный массив чисел;
- `k` — размер скользящего окна.

Окно последовательно перемещается по массиву на одну позицию вправо. Для каждого положения окна определяется максимальный элемент, после чего найденные значения записываются в результирующий массив.

Для эффективного решения используется двусторонняя очередь (`deque`). В очереди хранятся индексы элементов массива. При перемещении окна удаляются индексы элементов, которые вышли за его границы, а также элементы, которые больше не могут быть максимумом текущего или последующих окон.

[1, 3, -1, -3, 5, 3, 6, 7]
