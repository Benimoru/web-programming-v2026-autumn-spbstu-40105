\# Лабораторная работа №3

Вариант 17.

Реализована функция `maxSlidingWindow(arr, k)`, которая находит максимальный
элемент в каждом подмассиве длины `k`.

Пример:

`maxSlidingWindow(\[1, 3, -1, -3, 5, 3, 6, 7], 3)`

Результат:

`\[3, 3, 5, 5, 6, 7]`

\## Запуск

Функция находится в файле `solution.js`.
