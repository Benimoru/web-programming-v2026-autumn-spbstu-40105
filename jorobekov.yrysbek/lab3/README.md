# Лабораторная работа 3

## Задание

Вариант 17. Задача 3.

Необходимо реализовать функцию `maxSlidingWindow(arr, k)`, которая находит максимальный элемент в каждом последовательном подмассиве длины `k`.

Функция принимает массив чисел `arr` и размер окна `k`. Окно последовательно перемещается по массиву слева направо, а для каждого положения окна определяется максимальный элемент.

Пример:

```js
maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)
