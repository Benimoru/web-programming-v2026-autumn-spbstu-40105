# Лабораторная работа 3

## Задание

Вариант 17.

Задача 3. Реализовать функцию `maxSlidingWindow(arr, k)`, которая находит
максимальный элемент в каждом подмассиве длины `k`.

## Реализация

В файле `solution.js` экспортируется функция `maxSlidingWindow`.

Для поиска максимальных элементов используется двусторонняя очередь (`deque`), в
которой хранятся индексы элементов массива. При перемещении окна удаляются
индексы элементов, которые вышли за его границы, а также элементы, которые
меньше или равны текущему элементу.

Первый элемент очереди соответствует максимальному элементу текущего окна.
Найденные максимальные значения последовательно добавляются в результирующий
массив.

## Запуск

Импортируйте функцию из `solution.js` как ES module:

```js
import {maxSlidingWindow} from './solution.js';
```
