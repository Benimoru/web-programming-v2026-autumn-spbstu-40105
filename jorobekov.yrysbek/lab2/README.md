# Лабораторная работа 2

## Тема

Обработка строк и выделение частей слов с использованием регулярного выражения в JavaScript.

## Вариант

17

## Задание

Реализовать функцию `toAbbreviation(value)`, которая принимает строку и формирует из неё аббревиатуру.

Функция должна:

- принимать только строковое значение;
- выделять отдельные слова и числовые последовательности;
- корректно обрабатывать слова на русском и английском языках;
- учитывать слова, начинающиеся с заглавной буквы;
- обрабатывать последовательности заглавных букв;
- обрабатывать числа;
- возвращать строку, состоящую из первых символов найденных частей;
- выбрасывать `TypeError`, если передан аргумент, который не является строкой.

## Реализация

Основная функция находится в файле `solution.js`.

В программе используется регулярное выражение `WORD_PATTERN`, которое позволяет выделять из исходной строки отдельные части слов и числовые последовательности.

После выделения частей используется метод `map()`. Для каждой найденной части берётся первый символ, который переводится в верхний регистр с помощью `toUpperCase()`.

Затем полученные символы объединяются в одну строку методом `join("")`.

## Проверка типа данных

Перед обработкой выполняется проверка:

`typeof value !== "string"`

Если передан не строковый аргумент, функция выбрасывает:

`TypeError("Введите строку")`

## Используемые технологии

- JavaScript
- ES Modules
- Regular Expressions
- `String.match()`
- `Array.map()`
- `String.toUpperCase()`
- `Array.join()`
