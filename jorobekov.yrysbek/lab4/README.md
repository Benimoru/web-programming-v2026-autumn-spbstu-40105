# Лабораторная работа 4

## Задание

Вариант 17.

Задача 4. Создать класс `programmer` с полями `id`, `name`, `languages`.

Реализовать методы `addLanguage()`, `removeLanguage()` и геттер `languageCount`.

Для массива программистов реализовать группировку по языкам с помощью `Map`, получение уникального списка языков с помощью `Set`, поиск программистов по языку, группировку по количеству языков и поиск программистов с максимальным количеством языков.

Также реализовать пользовательский интерфейс с карточками программистов, добавлением и удалением программистов и языков, асинхронными операциями через `Promise` и `setTimeout()` и сохранением данных в `localStorage`.

## Реализация

В файле `model.js` реализован класс `Programmer` и функции для работы с коллекцией программистов.

В файле `main.js` реализован пользовательский интерфейс, добавление и удаление программистов и языков, поиск по языку, статистика и сохранение данных в `localStorage`.

В файле `styles.css` находятся стили страницы и адаптивная верстка.

## Запуск

Откройте `index.html` в браузере.
