## Лабораторная работа 4

## Задание

Вариант 17.

Задача 4.

Создать класс `programmer` с полями:

- `id` — уникальный идентификатор;
- `name` — имя программиста;
- `languages` — массив языков программирования.

Реализовать методы добавления и удаления языка, а также геттер количества языков.

Для массива программистов необходимо реализовать:

- группировку программистов по языкам с помощью `Map`;
- получение уникального списка языков с помощью `Set`;
- поиск программистов по заданному языку;
- группировку по количеству языков;
- поиск программистов с максимальным количеством языков.

Также необходимо создать пользовательский интерфейс с карточками программистов, формами добавления программиста и языка, кнопками удаления и автоматическим обновлением интерфейса.

Операции добавления и удаления выполняются асинхронно с использованием `Promise` и `setTimeout()`.

Список программистов сохраняется в `localStorage`.

## Реализация

В файле `model.js` реализован класс `Programmer` и функции для работы с коллекцией программистов.

Класс содержит поля `id`, `name` и `languages`.

Метод `addLanguage()` добавляет язык программирования, а метод `removeLanguage()` удаляет язык.

Геттер `languageCount` возвращает количество языков программиста.

Для группировки используется `Map`, а для получения уникальных языков используется `Set`.

В файле `main.js` реализована работа пользовательского интерфейса.

Карточки программистов создаются динамически. Пользователь может добавить или удалить программиста, добавить или удалить язык программирования, а также выполнить поиск программистов по языку.

Асинхронные операции реализованы с помощью `Promise` и `setTimeout()`.

Для сохранения данных используется `localStorage`.

В файле `styles.css` находятся стили страницы и адаптивная верстка.
